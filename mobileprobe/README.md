# MobileProbe 中文交互演示

双击 `index.html` 即可离线打开。请保留整个文件夹，特别是 `assets/`。

这是四个移动 AI 智能体安全案例的截图回放，适合课堂、组会或研究汇报。页面不会连接手机、运行 AI 或实际发送信息。

## 使用

- 点击案例卡片，或通过回放区域上方的下拉菜单切换案例。
- 点击“开始演示”；可暂停、继续、重播或逐步播放。
- 拖动进度条，跳转到指定步骤；可选择 0.75×、1×、1.5×、2× 倍速。
- “演示视图”隐藏介绍与案例笔记，方便投屏。按 Esc 退出。
- 空格暂停或继续，方向键切换步骤（焦点不在交互控件上时）。
- 点击“放大画面”检查截图文字；此时播放自动暂停。Esc 关闭。

## 中文版改进

界面、案例解释、步骤说明和操作提示改为中文。字幕放在画面下方，不覆盖原始截图。浅色手机舞台与白色讲解卡片区分视觉层次；当前用户目标始终可见；攻击画面以柔和红色边框与说明强调。关键攻击画面在 1× 下至少停留 10 秒。

## 证据边界

手机截图保留原语言与像素。截图来自手动操作采集，点击提示是独立的说明图层，部分坐标为推断，并非 AI 实时执行记录。

- 邮件：显示包含会议确认内容的短信发往额外号码。
- 购物：结算页显示两份商品、¥19.00，未展示提交订单或付款。
- Mastodon：仅展示点击“Add and Continue”、假弹窗关闭。
- Mattermost：仅展示点击“Verify”、假弹窗关闭，未展示追踪信息随后是否发出。

本副本内嵌清单与 `assets/replays/` 中的中文 JSON 保持一致，无需安装依赖。素材来源与校验信息见 `SOURCES.md`。
